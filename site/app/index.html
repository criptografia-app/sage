Try it with your wallet

Your own Safe, two AI co-signers, five minutes.

Connect a wallet on Sepolia. You get a 2-of-3 Safe owned by you and two demo agents. The proposal agent proposes and signs first, you review, and then you sign or tell the signer agent to sign and send. Everything happens on the Sepolia test network, and your wallet pays the gas (about 0.003 test ETH).

  1. Connect your walletMetaMask or any browser wallet, on Sepolia.
  2. Create your SafeOwners: you, proposal agent …, signer agent …. Any 2 of 3.
  3. Fund itSend it a little test ETH to play with. The signer agent also gets 0.0005 for gas, so it can send what you approve.
    ETH
  4. Ask the proposal agent to pay someone (or ask in the chat below, in plain language, for one or several payments)
    What SAGE knows about this payment
  5. Review the queue The proposal agent signed each payment first. Check them. Then sign any one yourself with your wallet, or approve them all: the signer agent adds signature 2 and sends each one, in order, paying the gas. You can also just say it in the chat below: "sign them all, I've reviewed".

Activity

    For this demo the two agents run in this browser tab with throwaway keys. In SAGE they run in your MCP server, and their keys stay in a vault. Your wallet is never asked for anything but a Sepolia transaction or a Safe signature, and you see each one before it goes.

    Using the real SAGE with Claude

    The demo above runs the agents in your browser. The real SAGE is an MCP server on your machine: its agents hold keys in an encrypted keystore or a vault, and Claude talks to it like this.

    git clone https://github.com/criptografia-app/sage && cd sage && npm install
node setup.js            # agent keys → Safe owners → 2-of-3

    Then add it to Claude Desktop (claude_desktop_config.json):

    { "mcpServers": { "sage": {
    "command": "node", "args": ["/path/to/sage/sage.js"],
    "env": { "SAGE_SAFE_ADDRESS": "0xYOUR_SAFE",
             "SAGE_PASSPHRASE_COMPLIANCE": "…", "SAGE_PASSPHRASE_EXECUTION": "…" } } } }

    Then ask Claude things like "what's pending in the wallet?", "propose 500 USDC to Acme", "simulate 12k to a new address" or "signer, approve all I've checked". The tools are sage_info, sage_pending, sage_propose, sage_simulate, sage_approve, sage_approve_all and sage_history.
